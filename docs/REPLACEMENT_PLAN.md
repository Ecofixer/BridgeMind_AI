# Previous Prototype Replacement Plan

## Decision

The old bridge-focused competition prototype is not the product foundation for Youchen AI OS or EcoFixer AI OS. Its project-specific agents, competition data, generated reports, large source documents, and product-facing legacy names remain outside this clean AI OS tree.

## Preserved as generic capabilities

Useful concepts may return later as internal capabilities behind the single AI OS experience:

- research and document understanding
- visual and multimodal understanding
- engineering or technical analysis
- cost and schedule analysis
- report generation
- task coordination

They must not reappear as separate product brands or bypass the common memory, permission, approval, and audit layers.

## Migration safety

1. The default branch is not modified by this completion branch.
2. The completion branch is based on the latest Youchen AI OS identity commit.
3. Runtime data stays outside Git.
4. Founder-only information cannot be downgraded to company visibility.
5. External side-effect tools are not enabled.
6. Automated tests must pass before merge.

## Repository settings still required

Source files cannot change repository visibility or erase public history. Before confidential use:

- choose the final repository name
- make the repository private
- enable branch protection and secret scanning
- review historical public commits and previously granted licenses
- avoid adding confidential company or personal data until the review is complete
